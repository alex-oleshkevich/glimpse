# System applets

These applets show and control the hardware and system services: sound, connections, displays, power and the session. Most of them need a system service to be installed; [Install](/start/install#arch-linux) lists which.

Some applets also have a table named after the service behind them, shown after the applet's own.
The service table changes the service for everything that uses it; the
applet table changes only that applet.
