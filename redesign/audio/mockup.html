Design Spec

Goal

The audio popover should feel like a compact modern control menu, not a dashboard. It should expose the common actions directly: output volume, input volume, output mute, input mute, device selection, output streams, and stream mute.

Constraints

  • Use the shared HTML mockup components from ../components.html and ../base.css.
  • Mirror the current shell component anatomy: popover-shell, hero-row, action-row, collapsible-section, list-item, and meter.
  • Keep the layout row-first: headers, menu rows, separators, sliders, switches, disclosure rows, and meters.
  • All interactive components in the mockup must be interactive in-browser.
  • Visual direction: macOS-like simplicity and polish, with Xfce-like explicit labels and predictable menus.

Interaction Notes

  • Disclosure rows expand and collapse in place.
  • Switch rows toggle aria-checked.
  • Slider rows update their visible percentage.
  • Device selection updates selected row state and subtitle text.
  • Stream mute icon buttons toggle pressed/muted state.
  • Visible row text must be human-readable; icon slots are semantic decoration and never abbreviation labels.
